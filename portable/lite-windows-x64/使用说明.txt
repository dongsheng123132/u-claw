虾盘 · U 盘精灵 · 轻量版（Windows x64）
版本：0.5.5-portable-preview（构建自 codex/u-picoclaw-portable @ 3acca4e）

一、启动
双击根目录的 虾盘.exe，会在本机启动页面并自动打开浏览器，所有操作都在页面里完成。
如需固定端口或不自动开浏览器，可在命令行运行：
  虾盘.exe -port 19222 -no-open

二、配置 AI 模型（两种方式任选其一）
1）自带 API：页面 → 模型设置 → 选择「自带 API · OpenAI 兼容」，填写：
   - API 基础地址 base_url：例如 https://api.moonshot.cn/v1（通常以 /v1 结尾，不要带 /chat/completions）
   - 模型 ID model：按服务商账户中实际可用的模型填写，需要 AI 操作工具时请选支持工具调用的模型
   - API Key
   保存后即可开始对话。保存不会调用模型；「测试连接」会发送一次模型请求，可能计费。
2）虾盘云：页面 → 钱包 → 联网获取钱包 / 填入已有钱包，再刷新余额。

三、数据与密钥保存在哪
- 首次运行会在本目录自动创建 data/，其中保存模型设置（data/settings/model.json）、PicoClaw 配置与工作区（data/pico/）、钱包凭证与对话记录。
- 数据与密钥全部随盘保存，换电脑可直接继续使用；data/ 含敏感凭证，请勿随包分发或上传。
- 轻量版会把 PicoClaw 程序本体缓存到当前电脑的 %LOCALAPPDATA%\Xiapan\（只缓存程序，不含密钥）。

四、轻量版说明
- 本包只含 Windows x64 主程序与 PicoClaw 引擎（约 45MB），不含随盘第三方工具、离线模型、驱动、源码，也不含官方完整界面启动器 picoclaw-launcher.exe。
- 页面里的「完整 PicoClaw」入口需要该启动器，轻量版请直接使用主页面里的 AI 服务。
- 电脑体检、网络检查、启动项查看、维护方案等系统类动作仍可直接使用，不联网、不消耗模型额度。

五、退出与拔盘
在页面点「退出」，或结束 虾盘.exe 进程；只关闭浏览器标签页不会停止后台 AI 服务。
确认程序退出后，再使用系统「安全弹出」移除 U 盘。
