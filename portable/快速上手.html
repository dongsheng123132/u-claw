U-Claw 快速上手

OpenClaw 2026.10.2 · Node.js 24.16.0 · 虾盘云默认，也可填自己的 Key

1. 插入 U 盘并启动

Windows 双击 Windows-Start.bat；Mac 双击 Mac-Start.command。启动后直接打开 OpenClaw WebUI。首次在 Mac 使用或换系统时，需要联网运行 setup.sh 准备当前平台依赖。本地安装会保留数据、备份旧程序。

2. 打开设备钱包

在 WebUI 侧栏点击「设备钱包」，或点击对话顶部「设备钱包 · 充值」。想用自己的模型：首次启动的配置页里选提供商，或选「自定义 · OpenAI 兼容」填 API 地址、模型和 Key。

3. 领取或恢复钱包

点击「一键领取额度」，或输入已有虾盘云密钥并点击「启用这把密钥」。默认模型 deepseek-v4-flash 会自动配置。

你的密钥就是你的钱包。点击「复制密钥」备份；换电脑后使用同一密钥恢复余额。已有密钥会沿用，启动时不会自动领取新钱包。

4. 充值并开始对话

点击「一键充值」打开充值页面，完成后点击「查询余额」，再回到对话。充值和钱包管理都发生在 WebUI 内部。

手动访问时，地址末尾带 #token=uclaw，端口以启动窗口显示的实际值为准。

微信、飞书、Telegram、QQ 等渠道接入入口已移除。后备配置中心仍可通过 Menu 脚本打开。

5. 附带的轻量版（虾盘精灵）

Windows 完整包里另附 lite-windows-x64/：虾盘精灵轻量版（约 45MB，不依赖 Node/OpenClaw）。双击 虾盘.exe 即用，支持自填任意 OpenAI 兼容 Key；老电脑、低速 U 盘或只做维护时用它，数据保存在该目录 data/。
