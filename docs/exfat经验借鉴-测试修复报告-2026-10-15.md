## 二、u-openclaw（v1-开源\u-claw）

### 测试基线（修复前）
- 全量测试 `node --test tests/*.test.mjs`：208 tests，**1 失败**：
  - `tests\wallet-control-ui.test.mjs` 进程级崩溃（exitCode **3221226505** = 0xC0000409 STATUS_STACK_BUFFER_OVERRUN）

### 根因定位
- 单跑该测试文件同样崩溃，无子测试输出；
- 逐模块二分定位：**`fs.cpSync` 复制中等大小目录即崩**（本机 Node v22.23.2 / Windows）：
  - 复制 3 文件小目录 → OK；
  - 复制 `portable/extensions/uclaw-wallet`（9 文件两层目录）→ 0xC0000409；
  - 复制 `portable/lib` → 0xC0000409；
  - 异步 `fs.promises.cp` → OK。
- **产品代码同样中招**：`portable/lib/prepare-wallet.mjs:39` 用 `fs.cpSync` 复制钱包插件目录——真实用户插 U 盘启动会走这条路径，等于「启动迁移必崩」。

### 修复
1. 新增 `portable/lib/copy-dir.mjs`：安全的同步递归目录复制（readdirSync + copyFileSync，符号链接按链接复刻，语义对齐 cpSync recursive+force），绕开 cpSync 内部栈溢出实现。
2. `portable/lib/prepare-wallet.mjs`：cpSync → `copyDirSync`。
3. `tests/wallet-control-ui.test.mjs`：5 处 cpSync → copyDirSync / copyFileSync（单文件）。
4. `tests/vendor-runtime-patches.test.mjs`：1 处 cpSync → copyDirSync。

### 复验
- `node --test tests/wallet-control-ui.test.mjs tests/vendor-runtime-patches.test.mjs`：9 tests，8 过 1 跳（UCLAW_TEST_CORE_DIR 未设）0 失败；
- **全量 `node --test tests/*.test.mjs`：215 tests，213 过，0 失败，2 跳**（修复前 1 失败 → 全绿）。

## 三、u-dsh（v2\u-dsh）

### 测试基线（修复前）
- 全量 `node --test test/*.test.js`：78 tests 全过（基线绿）。

### 发现的缺口
- `src/dsh-service.js` `startDshService`：`env: { ...environment }` **原样继承宿主机全部环境变量**传给 DSH 内核（main.js 也 `...process.env` 展开）。
- 对应 exFAT 坑#2 的两种风险：内核误认 provider「已配置」跳过引导/触发迁移；**静默继承宿主机主人的 API 凭证**（烧他人额度/抄 key）。U 盘「插谁电脑用谁的」，宿主残留必须剥。

### 修复
1. 新增 `src/env-sanitize.js`：`PROVIDER_ENV_VARS` 清单（u-claw 42 个 + OPENAI/ANTHROPIC/GEMINI/GOOGLE/XAI/AZURE/HF 等 8 个通用凭证变量）+ `sanitizeRuntimeEnv()`（只剥第三方凭证，保留 UDSH_*/UCLAW_*/LOCALAPPDATA 等自身与系统变量；幂等）。
2. `src/dsh-service.js`：spawn 内核前 `sanitizeRuntimeEnv(environment)`，不影响显式传入的 environment 与测试契约。
3. 新增 `test/env-sanitize.test.js`：5 用例（清单覆盖、剥离且不报值、保留自身变量、空值不剥、幂等）。

### 复验
- `node --test test/env-sanitize.test.js test/dsh-service.test.js`：13 tests 全过；
- **全量 `node --test test/*.test.js`：78 tests 全过**（含新增 5 个）。

## 五、遗留观察

1. u-claw 仓库当前有大量**先前未提交改动**（release.yml / OPENCLAW_VERSION / README 等，非本次修改），建议先确认再提交。
2. u-claw 的 `prepare-wallet.mjs`、`wallet-control-ui.test.mjs`、`vendor-runtime-patches.test.mjs` 显示为 **untracked**（仓库 .gitignore 规则所致），确认是否应纳入版本控制。
3. 本机 Node v22.23.2 的 `fs.cpSync` 复制中等目录即崩溃属环境级问题（异步 fs.cp 正常），已在代码与测试中规避；如换 Node 版本可再验证是否需回退。
4. u-dsh 的 env 净化只覆盖内核 spawn 路径；CLI 的系统命令 spawn（clip/open）不经内核，无需净化。
