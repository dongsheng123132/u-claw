# U-Claw 开源 U 盘版 · 减法改造交接文档

> 状态：设计草案，待评审（GPT-6）
> 日期：2026-10-18
> 范围：`portable/` 便携 USB 形态（Windows + macOS）
> 不在范围：`bootable/`（Linux 可启动）、`install/`（在线安装）、`u-claw-app/`（Electron 已弃用）

---

## [S1] 目标

U 盘版收敛为一个**稳定、可预期**的最小可用形态：

```
插上 U 盘 → 双击启动 → （首次）配置模型 → 进入 OpenClaw WebUI 对话
```

原则：
1. **只做减法**，不加新功能。
2. **不稳定、不好用、用户碰不到的，一律删**。删掉的代码比留下的更值钱。
3. 用户可见面越少越好；维护能力可留后门，但不能挡在主路径上。
4. 每删一块都要有测试兜底，确保剩下的路径不被删坏。

## [S2] 已定决策（与产品方确认过）

| # | 决策点 | 结论 |
|---|--------|------|
| D1 | 主入口形态 | **双击启动直进 WebUI**。`Windows-Start.bat` / `Mac-Start.command` 是唯一用户入口。首次未配模型则自动打开配置页，配完直进 WebUI。原 16 项菜单砍掉。 |
| D2 | 设备钱包 | **保留**。虾盘云领取 / 充值 / 恢复密钥 / 轮换能力与对应 `uclaw-wallet` 插件留下。 |

| D4 | OpenClaw 本体减法深度 | **待定** → 见 [S5]，留给评审确认。 |

## [S4] 目标形态

### 4.1 启动流程

```
双击 Windows-Start.bat / Mac-Start.command
  ├─ 检查 Node + OpenClaw 就绪（setup 没跑过则提示先跑 setup）
  ├─ 清理失效网关锁
  ├─ 起 config-server（配置页）
  ├─ 起 OpenClaw gateway
  ├─ 首次：打开配置页（config-server）→ 用户填 Key / 领钱包
  │        配置页保存后自动跳转 / 刷新到 WebUI
  └─ 已配置：直接打开 WebUI（gateway 端口 + token）
```

### 4.2 用户可见面（减法后）

```
portable/
  Windows-Start.bat          ← 唯一 Windows 入口
  Mac-Start.command          ← 唯一 Mac 入口
  setup.bat / setup.sh       ← 一次性下载运行时（保留）
  config-server/             ← 唯一配置页（含钱包）
  extensions/uclaw-wallet/   ← 钱包插件
  lib/                       ← 内部库（精简后）
  data/                      ← 运行时数据
  app/                       ← Node + OpenClaw（setup 下载）
```

配置页能力（`config-server/public/`）：
- 选择/填写模型 provider（虾盘云 + 自填 Key）
- 钱包：领取 / 充值 / 恢复 / 复制 Key / 余额
- 保存 → 写 `openclaw.json` → 进 WebUI

### 4.3 WebUI 里还剩什么

用户进的是 OpenClaw 自带 WebUI。**对话、工具调用、技能加载**这些 OpenClaw 能力是否裁剪，取决于 [S5] 的决定。

## [S5] 待定：OpenClaw 本体减法深度 ⚠️ 需评审

产品方原话：「甚至有些 openclaw 本身的 功能，都要做减法，比如 IM 功能，比如某个东西不好用，我们都可能要删除，确保稳定能用」。

**已知已删**（main 分支 razor 阶段）：聊天平台渠道 / 微信扫码 / 本地模型（Ollama、LM Studio）/ Electron 桌面版。

**待评审的候选裁剪清单**（按「不稳定 / 用户碰不到 / 砍了更稳」排序）：

| 候选 | OpenClaw 侧 | 砍掉的风险 | 建议 |
|------|-------------|-----------|------|
| IM / 消息渠道（微信、QQ、TG、Slack…） | channel / plugin | 已删大半；确认无残留 | **删干净** |
| 多 agent / 编排 / swarm | agents 多实例、handoff | 单用户 U 盘场景用不到 | **删** |
| 定时任务 / cron / 调度 | scheduler | 难排查、易空转 | **删** |
| 浏览器控制 / chrome-mcp | managed browser | 体积大、跨机不稳（曾在 USB 上出问题） | **删** |
| 设备配对 / 远程访问 | device pairing | 与「本地优先」定位冲突 | **删** |
| 自动更新 | update checker | 通道已 404 | **删** |
| 语音 / 多模态 | voice, a2ui | U 盘场景不稳 | **删** |
| 技能自动发现 / 市场 | skills marketplace | 随盘技能已删 | **删** |
| 单 agent 对话 + 工具调用 | core chat + tools | **必须保留** | 保留 |
| 文件读写 / shell 工具 | tools | 保留（但要考虑安全边界） | 保留 |
| 插件加载机制 | extensions | 保留（钱包插件要用） | 保留 |

**请评审确认**：
1. 上表「建议删」的项目，有没有哪项其实要留？
2. OpenClaw 是上游依赖（`node_modules/openclaw`），减法是走 **a) 启动参数/配置关闭**、**b) vendor patch 剥模块**、还是 **c) 换更小的内核**？这决定改造成本差一个数量级。
3. 「不好用就删」的判据是什么——有没有具体踩过坑的清单？

## [S6] 顺手要修的已知问题（测试时发现）

减法改造应一并处理，否则「稳定能用」不成立：

| # | 问题 | 位置 | 严重度 |
|---|------|------|--------|
| B1 | **config-server 路径穿越**：`GET /../../data/.openclaw/openclaw.json` 可读 API Key。`path.join(__dirname,'public',req.url)` 无前缀校验 | `portable/config-server/server.js:480-482` | 高 |
| B2 | **自动更新通道全 404**：`https://u-claw-oss.56chat.cn/u-claw-open/latest.json` 不存在；release.yml 不自动上传 | `lib/check-update.mjs` | 高（更新功能等于没有） |
| B3 | **配置中心保存冲掉钱包 provider**：保存非虾盘云模型后 `uclaw-cloud` 从 openclaw.json 消失 | `lib/merge-config.mjs`（PR #80 有修复未合） | 中 |
| B4 | 无静态文件路径穿越测试覆盖 | `tests/` | 中 |

> B1 修法：`path.resolve` 后校验结果 `startsWith(publicDir)`，否则 403。补一条穿越用例。
> B2 修法：二选一——(a) 把 latest.json 上传并进 release 流水线；(b) 跟随更新功能一起删掉。
> B3 修法：合 PR #80，或在减法中把「保存模型」逻辑改写时带上 keepProviders。

## [S8] 验收标准

1. 双击启动 → 未配模型进配置页 → 配完直进 WebUI → 能对话。
2. `portable/` 下用户可见文件 ≤ 10 个入口级文件（Start ×2、setup ×3、维护 ×2 以内）。
3. `skills-cn/`、`SkillHub.html`、`Welcome.html`、`U-Claw.html`、`Config.html`、`Windows-Menu.bat`、`Mac-Menu.command` 全部不存在。
4. `node --test "tests/*.test.mjs"` 全绿，且新增：路径穿越用例、启动主路径用例。
5. B1 路径穿越已修；B2 更新通道要么修好要么删干净；B3 钱包 provider 不再被冲掉。
6. 在 exFAT U 盘 + 干净 Windows 上真机跑通一遍（不能只在开发机验）。
