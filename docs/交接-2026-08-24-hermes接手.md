## 二、这一轮做完了什么

### 1. 干净机实测，验出一个阻断级 bug（`9368f0f`）

阿里云全新 Windows Server 2022（node/npm/git 全空）上，`setup.ps1` **直接失败，一个包都装不上**：

```
npm error command cmd.exe /d /s /c node scripts/preinstall-package-manager-warning.mjs
npm error 'node' is not recognized as an internal or external command
ERR OpenClaw installation failed.   (exit 1)
```

**根因**：用绝对路径调 `npm.cmd`，但 npm 跑生命周期脚本时经 `cmd.exe` 派生**裸 `node`**，走 PATH。
`setup.ps1` 全文一次 `$env:PATH` 都没有。**开发机上有 node，所以这个 bug 在本机 100% 测不出来。**

不是新 bug 是**漏修**：`setup.sh`(Mac) 当年踩同一个坑，用 `--ignore-scripts` 绕过了，
Windows 从没同步。Windows **不能照抄** `--ignore-scripts`——QQ 插件那步 `npm run build` 本身要 node。
改 PATH 一处修好全部 4 个 npm 调用点。

已在**同一台机从干净态复验**：exit=0 / 710s / openclaw 2026.7.1-2 / QQ 插件 / 17 个技能。

### 2. `runtime.host.purge` —— 一键清空本机残留（`d249848`）

发版硬约束「没有清理入口不许发版」的那一半。`scope=all` 删整棵 `<hostRoot>`，
`scope=slot` 只清当前 U 盘槽位。U 盘 `data/`（配置/会话/钱包）一律不动。

安全边界写死在 `kernel-manager.mjs` 的 `assertSafePurgeTarget()`，**别在调用方另写一份**。三道闸：
拒绝文件系统根 / 目录名必须是 `U-Claw`|`host`|槽位名 / 范围会碰到 `dataDir` 就拒绝执行。

`confirmation:'always'`（和 `runtime.gc` 的 `conditional` 刻意不同：gc 只删没人指向的旧内核，
purge 删整棵树含正在用的那版）。

### 3. 本机不可写时降级回落 U 盘（`82a0c5d`，**只做了库层**）

`prepareRuntimePaths()`：试本机 → 不可写就把第 2、3 层改挂 `<usb>/host/`，
返回 `mode:'host'|'portable-strict'|'failed'`。只有 U 盘也写不了才 `ok:false`。

**注意分层，别改错地方**：安装类动作（`runtime.seed/install`）拿到 `ok:false` **就该硬报错**，
现状正确；需要降级直跑的是**启动器**。

## 六、别踩的坑

- **别信开发机**（宪法 #4）。`setup.ps1` 那个 bug 就是活教材：本机有 node，永远测不出来。
  可达性/能否运行一律上干净机。
- **改完动作必须重新生成清单**，否则 `tests/action-parity.test.mjs` 立刻红：
  `node portable/lib/core/manifest.mjs > portable/action-parity.json`
- **PowerShell 传带空格的参数会被拆成多个 argv**。提示词要么单词、要么显式拼引号。
- **云测试机收尾必须 `teardown` + `reap`**，别只信 state 文件。忘了挂一天 ≈ ¥7.4。
- **Windows 解 tar.gz 必须点名 System32 的 bsdtar**（`tarBinary()`），PATH 上的 GNU tar
  会把 `C:\` 当远程主机。
- 破坏性/高危动作**不许** `confirmation:'never'`，确认在表现层之下强制。
