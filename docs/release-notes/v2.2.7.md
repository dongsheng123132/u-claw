# U-Claw v2.2.7

Windows NTFS 便携版：内置 OpenClaw 2026.10.2 和 Node.js 24.16.0。

- 首次启动直接选模型、填 API Key，保存后启动 Gateway 并进入 Dashboard；已有配置直接启动。虾盘云钱包为可选项。
- 配置、会话、记忆和工作区留在 U 盘。受管浏览器资料与 Node 编译缓存使用本机硬盘；浏览器网站登录需要在换电脑后重新完成。
- 启动前检查 NTFS、Node 与 OpenClaw 版本。不支持 exFAT/FAT32；它们在新内核实测中仍有文件写入错误。
- 随 main 的精简移除旧页面、渠道配置与独立技能页。渠道、技能、插件由 OpenClaw 自身管理。
- Windows 原生构建、锁定依赖和校验值；自动化只生成草稿，不再随上游版本自动公开未经验收的包。

下载 Windows 完整 zip，解压到 NTFS U 盘或本机 NTFS 目录，双击 `Windows-Start.bat`。模型 API 需要可用的 Key、余额与网络。

升级请关闭旧实例，把新版解压到新文件夹。先保留旧版和 `data/`，再将 `data/` 复制到新版；不要混合两版 `app/`，不要同时运行同一份数据。此前在配置页保存失败的渠道，需要检查 OpenClaw 中是否实际存在。

本次发布面向 Windows x64 / NTFS。macOS 可从源码准备独立原生运行时，本次未完成 Mac 真机验收；不承诺同一份 Windows `app/core` 能在 Mac 使用。没有改用 Docker。
