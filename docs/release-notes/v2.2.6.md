# U-Claw v2.2.6

本次为 Windows 便携版问题修复，继续使用 OpenClaw 2026.9.2 与 Node.js 22.22.3。

## 修复

- 渠道配置真正写入文件；服务器拒绝保存或无法读取当前配置时，页面停止并显示错误，避免假成功和部分配置覆盖。（#73，修复 #67）
- 钱包领取后的重试会补齐此前未同步的模型配置。（#74，修复 #66）
- 复制失败不再提示“已复制”，配置页按当前主模型回填服务商。（#71、#72，修复 #68、#69）
- 钱包引导更清晰，各模型服务商的 API Key 独立保存，补充 DeepSeek 等官方入口。（#76）
- 启动页等待网关真正就绪；连续双击复用已有实例，修复 Windows 单实例命令未执行的问题。（#77）
- 修正 Node 版本说明，明确 Windows U 盘的文件系统建议。（#75）

## 下载与使用

下载 `u-claw-portable-windows-v2.2.6.zip`，解压到 **NTFS 格式的 Windows U 盘**或电脑本地目录，双击 `Windows-Start.bat`。云模型需要联网和可用的钱包额度或自己的 API Key。下载页同时提供 `.sha256` 校验文件。

**升级前先备份旧目录的 `data`。** 请解压到新目录，退出旧实例后再迁移自己的 `data`，不要同时运行两份副本操作同一份数据。模型配置、钱包和会话继续保存在便携目录；浏览器用户目录及 Node 编译缓存使用本机硬盘。

**渠道用户请注意：** v2.1.18 起，配置页提交的渠道可能没有写入配置文件。升级后请检查 Telegram、QQ、飞书、企业微信等渠道；此前没有保存成功的配置需要重新填写并保存。

## 兼容性与验证

- Windows-only U 盘推荐 NTFS。exFAT 的首次工作区和对话兼容性仍在验证，本版不推荐 exFAT/FAT32，未加入实验性 exFAT 补丁。
- macOS 请使用本机目录或可写的原生文件系统；本次没有进行 Mac 实机验收。
- 修复集成测试 264 项通过；此前电脑与 NTFS 实体 U 盘各三轮真实启动、模型回复、保存与重启持久化通过。正式包的下载与实机验收结果在发布前补充。
- 个人微信入口仍不可用。
