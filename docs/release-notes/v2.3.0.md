# U-Claw v2.3.0

Windows 便携版候选：内置 OpenClaw 2026.10.2 和 Node.js 24.16.0。

- 首次启动直接选模型、填 API Key，保存后启动 Gateway 并进入 Dashboard；已有配置直接启动。虾盘云钱包为可选项。
- 配置、会话、记忆和工作区留在 U 盘。受管浏览器资料与 Node 编译缓存使用本机硬盘；浏览器网站登录需要在换电脑后重新完成。
- 启动前检查文件系统、Node 与 OpenClaw 版本。NTFS 使用原生文件系统路径；exFAT 自动启用经过版本和 SHA 校验的兼容补丁，使用目标存在则拒绝的改名发布，保留文件身份检查。不支持 FAT32。
- Windows 检测到旧会话数据库时，先备份配置和数据库，再调用上游官方迁移。首次升级可能需要数分钟；失败会保留备份并停止启动，日志在 `data/logs/session-upgrade.log`。
- 随 main 的精简移除旧页面、渠道配置与独立技能页。渠道、技能、插件由 OpenClaw 自身管理。
- Windows 原生构建、锁定依赖和校验值；自动化只生成草稿，不再随上游版本自动公开未经验收的包。

下载 Windows 完整 zip，解压后双击 `Windows-Start.bat`。仅 Windows 使用优先 NTFS；exFAT 下目录监听使用轮询，部分插件技能链接无法创建，首次启动和重启可能更慢。模型 API 需要可用的 Key、余额与网络。

升级请关闭旧实例，把新版解压到新文件夹。先保留旧版和 `data/`，再将 `data/` 复制到新版；不要混合两版 `app/`，不要同时运行同一份数据。此前在配置页保存失败的渠道，需要检查 OpenClaw 中是否实际存在。

本次候选面向 Windows x64。exFAT 能被 Mac/Windows 读写，并不代表两平台能共用原生运行时；Mac 实机共盘验收尚未完成，不承诺同一份 Windows `app/core` 能在 Mac 使用。没有改用 Docker。
