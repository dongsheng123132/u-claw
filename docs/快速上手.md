# U-Claw 快速上手

本版使用 OpenClaw 2026.10.9 和 Node.js 24.22.1。默认走虾盘云，也可以在首次启动的配置页填自己的 Key（第三方官方 Key，或「自定义 · OpenAI 兼容」）。

## 1. 插入 U 盘并启动

Windows 双击 `Windows-Start.bat`；Mac 双击 `Mac-Start.command`。启动后直接打开 OpenClaw WebUI。

首次在 Mac 使用或换系统时，需要联网运行 `setup.sh` 准备当前平台的依赖。安装到电脑可运行对应的 Install 脚本；已有数据会保留，旧程序会备份。

## 2. 打开设备钱包

在 WebUI 侧栏点击「设备钱包」，或点击对话顶部「设备钱包 · 充值」。想用自己的模型：首次启动的配置页里选提供商，或选「自定义 · OpenAI 兼容」填 API 地址、模型和 Key。

## 3. 领取或恢复钱包

点击「一键领取额度」，或输入已有虾盘云密钥并点击「启用这把密钥」。程序自动配置默认模型 `deepseek-v4-flash`。

**你的密钥就是你的钱包**。请点击「复制密钥」备份，换电脑后可以用同一密钥恢复钱包。已有密钥会沿用，不会在启动时自动领取新钱包。

## 4. 充值并开始对话

钱包内点击「一键充值」打开充值页面；完成后点击「查询余额」，再回到对话使用。充值和钱包管理都发生在 WebUI 内部。

若需要手动打开 WebUI，地址末尾带 `#token=uclaw`，端口以启动窗口显示的实际值为准。

渠道能力交由 OpenClaw 原生管理；没有配置的渠道不会运行。后备配置中心仍可通过 Menu 脚本打开。
## 5. 需要更轻？用虾盘 AI 优盘精灵

U-Claw 专注完整 OpenClaw。老电脑、低速 U 盘、只需要秒开聊天和系统维护时，用同作者的独立产品 **虾盘 AI 优盘精灵**：Windows 原生、约 44 MB、PicoClaw 内核，不装 Node/OpenClaw，插盘双击 `虾盘.exe` 即用。它和 U-Claw 各自发版、各自升级；源码与下载见 [dongsheng123132/xiapan-usb](https://github.com/dongsheng123132/xiapan-usb)。

Windows 完整包里仍附带 `lite-windows-x64/` 便于试用；长期使用请下载独立更新版。
