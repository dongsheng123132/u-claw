# U-Claw 快速上手

**只在 Windows 使用时，推荐 NTFS 格式的 U 盘。** 把整个 U-Claw 文件夹解压到盘内后，按下面步骤启动。exFAT 实测仍有文件写入错误，本版不支持；macOS 请使用本机目录或可写的原生文件系统。首次使用建议保持联网，以便完成模型配置。

## 第 1 步：双击启动

- Windows：双击 `Windows-Start.bat`。
- Mac：双击 `Mac-Start.command`。

首次启动会打开配置中心；以后启动完成后可直接进入对话页面。

## 第 2 步：在配置中心选模型

直接选择 **DeepSeek 等模型服务**，使用对应服务商的 API Key。

> ⚠️ **重要**：选择设备钱包时，**你的密钥就是你的钱包**——请按页面提示备份好密钥。重装系统、换电脑、U 盘损坏后，都要靠它找回余额；丢失即无法找回。

虾盘云钱包在「可选：虾盘云钱包与充值」中按需开启，不是启动前提。

![选模型](img/config-step1.png)

## 第 3 步：填写 API Key（仅使用自己的 Key 时）

这一步只在上一步选择自己的模型账号时出现。粘贴从模型服务商获取的 API Key，点击「保存并启动」。使用设备钱包时可跳过本步。

![填Key](img/config-step2.png)

## 第 4 步：打开对话页面

> 以下「第 4 步」都发生在配置中心的第 3 步（启动页）里。

保存成功后，等待网关就绪，页面自动进入 Dashboard，即可开始对话。启动脚本会自动打开正确地址；如果需要手动打开，地址是 `http://127.0.0.1:18789/#token=uclaw`（端口可能因占用顺延，以启动窗口提示为准，`#token=uclaw` 不能省）。

![配置完成](img/config-step3.png)

## 使用提示

- Windows U 盘推荐 **NTFS**；本版不支持 exFAT 或 FAT32。格式化会清空文件，请先备份。
- 遇到问题请到 [GitHub Issue](https://github.com/dongsheng123132/u-claw/issues) 反馈，并附上诊断工具生成的信息。
